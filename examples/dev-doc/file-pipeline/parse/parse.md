# 解析

上级：[文件处理流程](../file-pipeline.md)
依赖：[上传](../upload/upload.md)

负责把三种格式的文件转成统一的纯文本。

- 收到“文件已上传”消息后，先用文件 ID 查出文件名、格式和存储路径，再开始解析。
- 不同格式分开处理：
  - PDF：取文字层。没有文字层的页（比如扫描件）跳过，记下页码。
  - Word：取正文和表格。表格的每一行转成一句话。
  - Markdown：去掉格式符号，保留标题层级。
- 结果存成纯文本，放回对象存储，路径是原文件路径加上 `.txt`。
- 解析完，往队列里放一条“文件已解析”消息，里面只有文件 ID。
- 解析失败就标成“解析失败”，不重试，在后台列表里显示出来。
