# 文件处理流程

用户上传文档，系统把它转成纯文本，存起来给搜索用。

## 范围

- 支持 PDF、Word（.docx）、Markdown 三种格式。
- 单个文件最大 200MB。
- 只处理用户自己上传的文件，不抓网页。

## 流程

1. 上传：用户把文件传到对象存储。
2. 解析：把文件转成纯文本。
3. 建索引：把文本切成段，建全文索引。

每一步做完，往任务队列里放一条消息，下一步收到消息再开始。

## 子模块

- [上传](upload/upload.md)：用户上传文件，大文件分片传，支持断点续传
- [解析](parse/parse.md)：把三种格式的文件转成统一的纯文本
